# Dr. Maya Reynolds | Clinical Psychology Practice

A high-end, premium web presence for Dr. Maya Reynolds, a Clinical Psychologist based in Santa Monica, CA. This site is specifically designed to provide a trauma-informed, calming user experience for high-achieving professionals and creatives navigating burnout, chronic stress, and past trauma.

## Live Deployment
[View the live site here](https://dr-maya-reynolds-psyd-ca.vercel.app)

## Project Overview
This project focuses on translating a clinical therapeutic approach into a visually grounding digital experience. The design deliberately avoids traditional, sterile clinical templates in favor of cinematic, editorial-style coastal imagery, mindful whitespace, and a sophisticated color palette.

### Key Features & UX Decisions
* **Targeted Visual Identity:** Exclusive use of adult-focused, solitary, and abstract nature imagery to align strictly with the practice's adult-only demographic. 
* **Trauma-Informed Flow:** The user journey is structured to build trust incrementally—moving from an empathetic emotional hook, to clinical capabilities, to a transparent view of the physical office ("The Space of Serenity"), and finally to a low-pressure Call to Action.
* **Custom Typography:** Utilizes a high-contrast, elegant serif for structural headings, paired with a creative script to emphasize moments of emotional relief (e.g., "feeling safe").
* **Practice Optimization:** Clear, SEO-friendly pathways for both in-person Santa Monica sessions and California-wide secure telehealth.
